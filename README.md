# Permit to Work Generator

Программа для машинной команды: создаёт ежедневные **Daily Permit to Work** (форма MSC F-V9.3A)
из Word-шаблона. Оформление в стиле Windows 95. Для каждого дня подбираются разная работа
и разный экипаж.

## Запуск

```
pip install -r requirements.txt
python main.py
```

Нужен Python 3.9+ с tkinter (в установщике Python для Windows tkinter стоит по умолчанию).

При первом запуске программа попросит выбрать папку, куда сохранять пермиты
(**Options > Settings**).

## Как пользоваться

### Auto generate
1. В календаре **From** выберите первый день, в календаре **To** последний.
2. Нажмите **Generate**: справа появится план, по одной строке на каждый день.
3. Проверьте план. **Reroll** заново подбирает выбранные строки, **Edit...** (или двойной клик)
   позволяет поправить строку вручную, **Remove** удаляет строку.
4. Нажмите **Create files**: в папке появятся файлы вида `2026-10-12 ME Fuel Valves Overhaul.docx`.

### Manual
Выберите дату и работу, отметьте участников (или нажмите **Auto-pick crew**),
при необходимости поменяйте подписантов разделов 5–7 и нажмите **Create file**.

### History
Список всех созданных пермитов. История нужна, чтобы при следующей генерации учесть
прошлые дни. Если удалить запись, файл на диске останется.

## Как подбираются работы и экипаж

- Работа не повторяется чаще, чем раз в *N* дней (Settings, по умолчанию 7). Чем дольше
  работу не делали, тем выше шанс, что её выберут.
- У каждой работы есть **Responsible ranks** (кто отвечает): главный двигатель — 2E,
  дизель-генераторы и котёл — 3E, сепараторы и насосы — 4E, sewage, incinerator,
  спасательные шлюпки — 5E, электрика — AEO. Если ответственный вёл работу вчера,
  сегодня чаще выбирается работа другого механика.
- Помощники (Extra officers, Ratings) выбираются из тех, кто реже участвовал в последние дни.
- CE в работах не участвует: он только A.O. (выбирается в Settings).
- Подписи в форме:
  - **5) P.C.**: самый младший офицер в команде;
  - **6) Transfer**: следующий по старшинству (если офицер в команде один, раздел 6 остаётся пустым);
  - **7) P.C.**: ответственный за работу.

  Всё это можно поменять вручную через **Edit...** или во вкладке **Manual**.

## Данные (JSON)

Все данные лежат в папке `data/`. Их можно редактировать прямо в программе через меню **Data**:

| Файл | Что внутри |
|---|---|
| `jobs.json` | список работ: Location, Plant, Work, номер Risk Assessment, кто отвечает и сколько помощников |
| `crew.json` | экипаж: ранг, имя, фамилия, своя должность для подписи (например, *Asst. Second Engineer*), на борту или нет |
| `ranks.json` | ранги: короткое имя для *Permit issued to*, полное для подписей, старшинство |
| `settings.json` | настройки (создаётся программой) |
| `history.json` | история созданных пермитов (создаётся программой) |

Когда член экипажа списывается, снимите у него галочку **On board** и добавьте сменщика.

> Номера Risk Assessment сейчас заглушки `RA-E01…RA-E51`. Замените их на реальные
> в **Data > Jobs**.

## Шаблон Word

`templates/ptw_template.docx` — ваша форма, в которой значения заменены на поля:

`{{DATE}} {{YEAR}} {{PERMIT_NO}} {{LOCATION}} {{PLANT}} {{WORK}} {{ISSUED_TO}} {{RA_NO}}
{{AO}} {{PC}} {{TRANSFER_TO}} {{TRANSFER_DATE}} {{PC_CLOSE}} {{TIME_ISSUE}} {{TIME_TRANSFER}} {{TIME_CLOSE}} {{SHIP}}`

Шаблон можно править в Word: поля можно переносить и удалять, остальной текст и
оформление сохранятся. Свой шаблон указывается в **Settings > Word template**.
Если форма обновится (новая ревизия), из заполненного образца можно заново сделать шаблон:

```
python tools/make_template.py "Daily permit to work.docx" templates/ptw_template.docx
```

## Сборка .exe (Windows)

```
pip install pyinstaller
pyinstaller --noconfirm --windowed --name PTW_Generator ^
    --add-data "data;data" --add-data "templates;templates" ^
    --hidden-import babel.numbers main.py
```

Готовая программа будет в `dist/PTW_Generator/`. При первом запуске рядом с exe создаются
папки `data/` и `templates/`: там хранятся ваши данные, и при пересборке они не теряются.
