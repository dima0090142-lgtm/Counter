# Permit to Work Generator

Программа для машинной команды: создаёт ежедневные **Daily Permit to Work** (форма MSC F-V9.3A)
из Word-шаблона. Оформление в стиле Windows 95, интерфейс на английском или русском языке.
Для каждого дня подбираются разная работа и разный экипаж, и каждый пермит помещается
на один лист A4.

**Сборка exe и проверка печати описаны в [BUILD.md](BUILD.md).**

## Запуск

```
pip install -r requirements.txt
python main.py
```

Нужен Python 3.9+ с tkinter (в установщике Python для Windows tkinter стоит по умолчанию).

При первом запуске программа попросит выбрать папку, куда сохранять пермиты
(**Options > Settings**). Там же можно включить русский язык: **General → Language → Русский**.

## Заставка и звуки

При запуске на 2 секунды появляется небольшая заставка в духе экрана загрузки Windows 95:
небо с облаками, иконка, название и бегущая цветная полоса (заставку можно отключить в
**Настройки → Общие**). Окна сообщений тоже сделаны в стиле Win95. Иконка программы —
лист пермита с каской (`icons/`, перерисовать: `python tools/make_icon.py`).

Звуки короткие (0,35–1,5 с) и синтезированы специально для программы (оригинальные звуки Windows защищены
авторским правом, поэтому их в программе нет). Они лежат в папке `sounds/`:

| Файл | Когда играет |
|---|---|
| `startup.wav` | запуск программы |
| `tada.wav` | файлы пермитов созданы |
| `ding.wav` | информационное сообщение |
| `exclamation.wav` | предупреждение |
| `chord.wav` | ошибка |
| `shutdown.wav` | выход из программы |

Любой файл можно заменить своим `.wav` с тем же именем. Например, в `C:\Windows\Media`
до сих пор лежат `tada.wav`, `ding.wav` и `chord.wav`, а звук запуска Windows 95, если он
у вас есть, называется `The Microsoft Sound.wav` (переименуйте его в `startup.wav`). Звуки выключаются в **Настройки → Общие → Звуки**, кнопка
**Проверить** проигрывает звук для проверки. Заново синтезировать стандартные звуки:
`python tools/make_sounds.py`.

## Настройки (Options > Settings / Параметры > Настройки)

| Вкладка | Что настраивается |
|---|---|
| **General / Общие** | язык интерфейса, размер шрифта интерфейса, название судна, A.O., звуки, заставка |
| **Files / Файлы** | папка для пермитов, свой шаблон Word, шаблон имени файла с примером, открывать ли папку после создания |
| **Permit / Пермит** | время в разделах 5, 6 и 7; номер пермита (по дню года / сквозной / не заполнять); ставить ли галочки A.O. и P.C. в разделах 2 и 3 (по умолчанию да) |
| **Generation / Генерация** | пермитов в день, через сколько дней можно повторить работу, дни недели без пермитов, кто становится P.C. вместо 4E/5E (2E, 3E по очереди), кто в первую очередь ставит LOTO (ETO, AEO) |
| **Print / Печать** | уменьшать ли шрифт длинного текста и минимальный размер шрифта |

Кнопка **Defaults / По умолчанию** сбрасывает настройки, но оставляет папки, название
судна, номер и A.O. Название судна в окне программы не показывается: оно печатается только
в поле *Ship:* формы, так что программой можно пользоваться на разных судах.

### Номер пермита (Consecutive Permit No)

По умолчанию номер — день года: 12 октября → `E- 285/2026`. Если в этот день пермитов
несколько, к дню добавляется номер: `285-1`, `285-2`… Если пермит на этот день уже
был создан раньше (`285`), следующий получит `285-2`. Номер виден в плане (столбец **№**)
ещё до создания файлов; в ручном режиме его можно вписать самому.

## Как пользоваться

### Auto generate
1. В календаре **From** выберите первый день, в календаре **To** последний.
2. Нажмите **Generate**: справа появится план, по одной строке на каждый день.
3. Проверьте план. **Reroll** заново подбирает выбранные строки, **Edit...** (или двойной клик)
   позволяет поправить строку вручную, **Remove** удаляет строку.
4. Нажмите **Create files**: в папке появятся файлы вида `2026-10-12 ME Fuel Valves Overhaul.docx`.

### Manual
Выберите дату и работу, отметьте участников (или нажмите **Auto-pick crew**),
при необходимости поменяйте подписантов разделов 5–7 и нажмите **Create file**.

### History
Список всех созданных пермитов. История нужна, чтобы при следующей генерации учесть
прошлые дни. Если удалить запись, файл на диске останется.

## Как подбираются работы и экипаж

- Работа не повторяется чаще, чем раз в *N* дней (Settings, по умолчанию 7). Чем дольше
  работу не делали, тем выше шанс, что её выберут.
- У каждой работы есть **Responsible ranks** (кто отвечает): главный двигатель — 2E,
  вспомогательные двигатели (AE), котёл, STP, компрессоры — 3E, сепараторы и топливо — 4E,
  насосы и фильтры водяных систем, шлюпки — 5E, электрика — AEO. Если ответственный вёл
  работу вчера, сегодня чаще выбирается работа другого механика.
- Помощники (Extra officers, Ratings) выбираются из тех, кто реже участвовал в последние дни.
- CE в работах не участвует: он только A.O. (выбирается в Settings).
- **P.C. (разделы 5, 6, 7) — только 2E, 3E и ETO/AEO.** 4E (кадет), 5E (Junior Engineer)
  и рядовые P.C. не бывают. Если работу ведёт 4E или 5E, в пермит добавляется 2E или 3E
  (по очереди — кто реже был P.C.), он и подписывает разделы 5 и 7. Кто может быть P.C.,
  задаётся галочкой у ранга (**Данные → Ранги**), для отдельной работы — полем
  «Ранги P.C.».
- Подписи в форме (из тех, кто может быть P.C.):
  - **5) P.C.**: самый младший из них;
  - **6) Transfer**: следующий по старшинству (если P.C. в команде один, раздел 6 пустой);
  - **7) P.C.**: ответственный за работу (или старший).
- **4) LOTO.** По умолчанию пусто: генератор LOTO не ставит. Галочку **LOTO** вы ставите
  сами — в **Edit...** (двойной клик по строке плана) или во вкладке **Manual**. После этого
  в *Rank/Name (A.O.)* предлагается электромеханик (ETO / AEO), если его нет на борту — P.C.;
  выбрать можно из офицеров, которые могут ставить LOTO, и ETO/AEO. *Equipment Tagged Out*
  и время заполняются ручкой. У работы есть подсказка «Обычно нужен LOTO» — она только
  показывается в описании работы и ничего не ставит сама.
- Галочки A.O. и P.C. в разделах 2 и 3 ставятся в файле (можно выключить в настройках).

  Всё это можно поменять вручную через **Edit...** или во вкладке **Manual**.

### Почему 4E (кадет) не может быть P.C. — и PSC

P.C. (Authorized Person in Charge) по SMS — это компетентный офицер, назначенный
отвечать за безопасность работы. Кадет или trainee без диплома (CoC) не может быть P.C.:
если на проверке PSC (или при аудите ISM) в пермите P.C. окажется кадет или человек,
которого нет в судовой роли под этой должностью, это записывают как недостаток
по системе управления безопасностью (ISM). Поэтому программа не даёт выбрать 4E/5E
в разделах 5–7 и добавляет P.C. из 2E/3E. Должности в подписях берутся из списка экипажа
(**Данные → Экипаж**), держите их как в crew list.

## Данные (JSON)

Рабочие данные лежат в папке `data/` (создаётся при первом запуске из `defaults/`).
Их можно редактировать прямо в программе через меню **Data**:

| Файл | Что внутри |
|---|---|
| `jobs.json` | список работ: Location, Plant, Work, номер Risk Assessment, кто отвечает и сколько помощников, нужен ли LOTO |
| `crew.json` | экипаж: ранг, имя, фамилия, своя должность для подписи (например, *Asst. Second Engineer*), на борту или нет |
| `ranks.json` | ранги: короткое имя для *Permit issued to*, полное для подписей, старшинство, может ли быть P.C., может ли ставить LOTO |
| `settings.json` | настройки (создаётся программой) |
| `history.json` | история созданных пермитов (создаётся программой) |

Когда член экипажа списывается, снимите у него галочку **On board** и добавьте сменщика.

В списке 136 работ: 2E — 28, 3E — 37, 4E — 34, 5E — 23, AEO — 14. Среди них чистка
фильтров и сеток насосов (топливных, масляных, забортной и пресной воды, осушительных,
балластных, пожарных), замена фильтров турбокомпрессоров ГД и AE, чистка сепараторов
HFO, DO, LO.

Новые работы не появятся у вас сами, если программа уже запускалась (ваш `data/jobs.json`
не трогается). Нажмите **Данные → Загрузить стандартный список работ…**.

> Номера Risk Assessment сейчас заглушки `RA-001…RA-136`. Замените их на реальные
> в **Data > Jobs**. В пункте 3.5 под номер мало места (около 7 символов при 9 pt);
> более длинный номер напечатается мельче.

## Шаблон Word

`templates/ptw_template.docx` — ваша форма, в которой значения заменены на поля:

`{{SHIP}} {{DATE}} {{YEAR}} {{PERMIT_NO}} {{LOCATION}} {{PLANT}} {{WORK}} {{ISSUED_TO}} {{RA_NO}}
{{LOTO_NAME}} {{AO}} {{PC}} {{TRANSFER_TO}} {{TRANSFER_DATE}} {{PC_CLOSE}} {{TIME_ISSUE}} {{TIME_TRANSFER}} {{TIME_CLOSE}}`

Галочки A.O. / P.C. разделов 2 и 3 — это поля-флажки Word; программа ставит их сама.

Шаблон можно править в Word: поля можно переносить и удалять, остальной текст и
оформление сохранятся. Свой шаблон указывается в **Settings > Word template**.
Если форма обновится (новая ревизия), из заполненного образца можно заново сделать шаблон:

```
python tools/make_template.py "Daily permit to work.docx" templates/ptw_template.docx
```

## Печать на одну страницу

Длинный текст автоматически печатается мельче, а при крайней необходимости обрезается с «…»:
форма всегда остаётся на одном листе. Проверка всех работ через LibreOffice:

```
python tools/check_print.py
```
