# Тренажёр судового ГРЩ — «Ввод генератора в параллель»

Один самодостаточный файл **`msb-trainer.html`** (HTML + CSS + чистый JS, без библиотек и сети).
Открывается двойным щелчком в браузере на ПК или на телефоне (альбомная ориентация, тач).

Установка: 3 дизель-генератора 440 В / 60 Гц / 1200 кВт / cos φ 0,8 (1500 кВА, Iном ≈ 1968 А),
общие шины 440 В, трансформатор 440/220 В, 16 фидеров потребителей.

## Щит

| Панель | Состав |
|---|---|
| **No.1…No.N GENERATOR** | V (0–600), A (0–2500), kW (−300…1500, зона обратной мощности), Hz (55–65), cos φ; переключатели RS/ST/TR и R/S/T; ключ GOVERNOR LOWER/RAISE с самовозвратом; потенциометр VOLTAGE ADJ.; ENGINE START/STOP, ACB CLOSE/OPEN, RESET; лампы RUNNING, READY, HEATER ON, ACB CLOSED/OPEN/TRIPPED; SPACE HEATER; ЖКИ двигателя |
| **SYNCHRONIZING PANEL** | синхроноскоп 360° (по часовой — FAST), лампы «на погасание» / «вращающийся огонь», двойные V и Hz (BUS/INC), реле контроля синхронизма (25) с индикацией ΔU/Δf/Δφ, SYNC PERMIT, ключи SYNC SELECT (OFF/G1…), SYNC MODE MAN/AUTO, SYNC CHECK BYPASS; GOVERNOR, VOLT ADJ. и ACB выбранного генератора |
| **BUS & PMS PANEL** | V и Hz шин, суммарный kW, мегомметр изоляции 440/220 В, лампы земли R/S/T с кнопкой TEST, вольтметр 220 В, ключ PMS MANUAL/AUTO, очерёдность резерва |
| **FEEDER PANEL** | автоматы потребителей с лампами, токами, кВт и состоянием (ESS / PT-1 / PT-2 / HEAVY / 220V) |
| **SINGLE LINE DIAGRAM** | однолинейная схема: АВ, шины под напряжением, анимированные потоки мощности (красный — обратная) |
| **ALARM MONITORING PANEL** | световые окна по генераторам и общие; мигание до ACK, ревун (Web Audio), ACK / SILENCE / RESET / LAMP TEST; журнал событий с судовым временем |

Пульт инструктора (кнопка **ИНСТРУКТОР**): время ×1/×5/×10, пауза, сброс; сценарии
(«Один на шинах — ввести второй», «Три в параллель — вывести один», «Блэкаут», «Холодное судно», «Свободная работа»);
неисправности (топливо, регулятор, AVR, возбуждение, масло, перегрев, подшипник, дифзащита, небаланс,
КЗ на шинах / фидере, замыкание на землю, утечка воздуха, отказ реле синхронизма);
живые Δφ/Δf/ΔU и оценка каждого включения (угол, Δf, ΔU, бросок тока, обратная мощность,
распределение нагрузки, синхроноскоп, cos φ) и действий оператора.

## Структура кода (модули внутри файла)

```
0. CONFIG       — все номиналы, уставки, таблица защит, потребители, PMS, шкалы и стиль приборов
1. U, Cx        — утилиты, комплексная арифметика (фазоры, о.е.)
2. Audio        — ревун и щелчки АВ (Web Audio)
3. Log, Alarms  — журнал; табло: OFF → ALM → ACK → RTNACK (→ RESET), reflash, ревун
4. Model        — GenSet (дизель, регулятор, AVR, ротор, АВ, температуры), Consumer, Model.solve (сеть)
5. Protection   — защиты генератора по таблице, дизеля, фидеров (селективность), контроль шин, изоляция
6. Automation   — Sync (реле 25, синхроноскоп), AutoSync (автосинхронизатор), PMS
7. Instructor   — неисправности, сценарии, Assess (оценка)
8. Sim          — фиксированный шаг 20 мс, накопитель времени, ×1/×5/×10, пауза
9. UI components— Gauge, Synchroscope, Rotary, SpringKey, Knob, лампы, кнопки
10. UI panels   — GenPanel, SyncPanel, BusPanel, FeederPanel, MimicPanel, AlarmPanel, InstrUI
11. Layout/loop — автокомпоновка (сетка на ПК, листание панелей на телефоне), главный цикл
```

### Физическая модель (кратко)
* **Сеть**: каждый генератор — сверхпереходная ЭДС E″ за X″d в узле шин; нагрузки — проводимости
  (двигатели — с пусковым током и низким cos φ). E″ релаксирует к E′ − j(X′d − X″d)·I с τ″ = 60 мс,
  поэтому бросок при включении ≈ |ΔE|/ΣX″d (≈ 10·sin(φ/2) Iн при одном генераторе на шинах),
  а установившийся режим и синхронизирующая мощность определяются X′d.
* **Ротор**: 2H·dω/dt = Tм − Tэ − потери − D·(ω − ωср); угол δ интегрируется в осях 60 Гц → качания после включения.
* **Дизель**: прокачка → проворачивание воздухом (расход воздуха) → подача топлива → разгон по рампе; регулятор со
  статизмом 4 %, ограничение рейки, запаздывание сгорания, моторный режим ≈ 10 % Pном, ограничение рейки холодного двигателя.
* **AVR**: ПИ-регулятор, статизм 3 % по Q, плавное возбуждение, V/Hz-ограничение, форсировка.
* **Включение АВ**: собственное время 80 мс; ≤ 10° — мягко; 10–30° — толчок и качания; > 30° — MCR отключает входящий;
  ≳ 85° — отключаются оба (блэкаут); > 120° — механический удар, остановка агрегата.

## Настройка
* Число генераторов: `CONFIG.gen.count` (компоновка, табло, ключи и PMS подстраиваются).
* Уставки и выдержки защит: таблицы `CONFIG.protection.gen / engine / bus / feeder`.
* Потребители: `CONFIG.consumers` (кВт, cos φ, категория, параметры пуска).
* Внешний вид приборов: `CONFIG.gaugeStyle` (цвета, геометрия `sector90`/`quadrant` или объект
  `{px, py, R, a0, a1}`), шкалы — `CONFIG.meters`, `busMeters`, `syncMeters`.
  **Фото циферблата**: `CONFIG.gaugeStyle.faceImages = { V: 'data:image/png;base64,…', kW: '…' }`
  (ключ — единица измерения) или опция `faceImage` у конкретного `Gauge`; `drawScale: false` — не рисовать шкалу поверх фото.

## Проверка
Отладочный доступ из консоли браузера: `window.SIM` (`SIM.Sim.advance(сек)`, `SIM.Instructor.load('blackout')` и т.д.).
Каждый этап проверялся в headless Chromium (ПК 1920×1080 и телефон 844×390 с тачем): пуск, синхронизация при углах
5–180°, обратная мощность, срыв топлива, перегрузка и preferential trip, масло/перегрев/разнос, КЗ на шинах,
PMS (автопуск, тяжёлые потребители, блэкаут, вывод лишнего), сквозной ввод в параллель через интерфейс.
