# Сборка программы (Windows)

В результате получится папка `PTW_Generator` с файлом `PTW_Generator.exe`. Её можно
скопировать на любой компьютер с Windows 10/11: Python и интернет там не нужны.

## 1. Что установить (один раз)

1. **Python 3.10 или новее** с <https://www.python.org/downloads/>.
   В первом окне установщика обязательно отметьте **Add python.exe to PATH**.
   Остальное оставьте по умолчанию: tkinter (графика) устанавливается вместе с Python.
2. Проверьте в командной строке (`Win+R` → `cmd`):
   ```
   python --version
   ```
   Должно появиться `Python 3.x.x`.

## 2. Скачать проект

Вариант А, без git: на GitHub откройте ветку `claude/permit-to-work-generator-ad1sz9`,
нажмите **Code → Download ZIP** и распакуйте архив, например в `C:\PTW`.

Вариант Б, с git:
```
git clone -b claude/permit-to-work-generator-ad1sz9 https://github.com/dima0090142-lgtm/Counter.git C:\PTW
```

## 3. Собрать

**Автоматически.** Дважды щёлкните `build.bat` в папке проекта. Скрипт:
1. установит пакеты (`python-docx`, `tkcalendar`, `pyinstaller`, `pytest`);
2. прогонит тесты;
3. соберёт программу.

**Вручную**, те же шаги в `cmd`:
```
cd C:\PTW
python -m pip install -r requirements.txt pyinstaller pytest
python -m pytest -q tests
python -m PyInstaller --noconfirm --clean --windowed --name PTW_Generator ^
    --add-data "defaults;defaults" --add-data "templates;templates" --add-data "sounds;sounds" ^
    --add-data "icons;icons" --icon icons\ptw.ico ^
    --hidden-import babel.numbers main.py
```

Готовая программа: `C:\PTW\dist\PTW_Generator\PTW_Generator.exe` (с иконкой — лист
пермита с каской).

> Нужна **вся папка** `dist\PTW_Generator`, а не только exe: рядом лежит `_internal`
> с библиотеками. Для удобства на exe можно сделать ярлык на рабочем столе.

### Один exe-файл вместо папки (по желанию)

Добавьте к команде PyInstaller `--onefile`. Получится один файл `dist\PTW_Generator.exe`.
Он запускается на пару секунд дольше, зато его проще переносить.

## 4. Первый запуск

- Рядом с exe появятся папки `data\` (экипаж, работы, настройки, история),
  `templates\` (шаблон Word) и `sounds\` (звуки). **Это ваши данные:** при обновлении программы
  заменяйте только exe и `_internal`, а `data`, `templates` и `sounds` оставляйте.
- **Обновление с прошлой версии.** Ваш список работ в `data\` не меняется сам. Чтобы получить
  новые работы (фильтры, сепараторы, переименование DG → AE), откройте
  **Данные → Загрузить стандартный список работ…**: «Да» заменяет ваш список стандартным,
  «Нет» только добавляет недостающие работы.
- Стандартные списки (экипаж, работы, ранги) лежат внутри программы в `defaults\`,
  их никто не меняет; программа копирует их в `data\` при первом запуске.
- Программа попросит выбрать папку для пермитов (**Параметры → Настройки → Файлы**).
- Язык меняется в **Настройки → Общие → Язык** (English / Русский).

## 5. Проверка печати на одну страницу

Форма заполнена до конца листа, поэтому **одна лишняя строка уводит её на вторую
страницу**. Программа защищается от этого так:

1. Каждое значение (Location, Plant, Work, Issued to, подписи, № RA) печатается
   Times New Roman 9 pt. Перед сохранением ширина текста считается по метрикам шрифта.
2. Если текст не помещается в строку, его шрифт уменьшается (до 6.5 pt, настраивается
   в **Настройки → Печать**).
3. Если в «Issued to» слишком много людей, ранги пишутся коротко: `2E DMITRII`.
4. Если и этого мало, текст обрезается с «…», и программа показывает, в каком файле это произошло.
5. Редактор работ (**Данные → Работы**) сразу предупреждает о слишком длинном тексте.

Как проверено:
- `tools/check_print.py` строит пермит на **каждую** из 136 работ с максимальной
  командой и самыми длинными именами (плюс P.C. 2E/3E, раздел 6, LOTO, галочки A.O./P.C.),
  и стресс-пермит с очень длинным текстом и всем экипажем. Затем конвертирует их через
  LibreOffice в PDF и проверяет, что везде **ровно 1 страница** и каждое значение стоит
  в одной строке. Результат: 137 из 137.
- Чтобы повторить проверку у себя, установите LibreOffice и запустите
  ```
  python tools/check_print.py
  ```
  Это стоит делать, если вы правили шаблон или длинные тексты работ.
- LibreOffice и Word раскладывают текст почти одинаково (Liberation Serif и
  Times New Roman совпадают по ширине букв), а программа оставляет небольшой запас.
  Тем не менее при первом запуске откройте один пермит в Word и посмотрите
  **Файл → Печать**: внизу должно быть «1 из 1».

## Если что-то не так

| Проблема | Решение |
|---|---|
| `python` не найден | Переустановите Python с галочкой **Add python.exe to PATH** |
| `No module named tkinter` | Запустите установщик Python → Modify → отметьте **tcl/tk and IDLE** |
| Антивирус ругается на exe | Так бывает с PyInstaller. Добавьте папку в исключения или используйте сборку без `--onefile` |
| Нет звука | Проверьте **Настройки → Общие → Звуки** и что рядом с exe есть папка `sounds` с файлами `.wav` |
| Календарь не открывается в exe | Проверьте, что в команде есть `--hidden-import babel.numbers` |
| Изменения в работах пропали после обновления | Вы заменили папку `data`. Восстановите её из старой копии |
